三、Altium Designer 22+ 电路仿真专题（电流 / 热 / 电磁）

先说结论（很重要）：GitHub 上不存在「直接嵌入 AD 22+ 内部、开箱做电流/热/电磁仿真」的成熟开源插件。经与 Altium 官方文档核实，AD 22+ 的仿真由三条线各管一块：① 电流 → Power Analyzer by Keysight（AD 22.10+ 扩展，PI-DC：电压降 / 电流密度 / 过孔电流，PCB 内热力图 + HTML 报告）；② 高速信号与电磁 → SI Analyzer by Keysight（Open Beta，布局后 SI：阻抗 / 延迟 / 插入损耗 IL / 回波损耗 RL，ODB++ 导入求解器）；③ 热 → AD 无原生热求解器，必须走 Ansys Icepak（可直接导入 AD 的 ECAD 数据，并与 SIwave / Q3D / HFSS 做焦耳热与电磁-热耦合）。开源社区的角色是给 AD 做仿真数据的导入导出、前后处理与自动化，或通过 Ansys / COMSOL 的官方 Python 接口把 AD 板级数据接进求解器。下面按这个真实格局分三组给出。

A. AD 22+ 原生 / 官方仿真能力非 GitHub 项目，但是 AD 用户做仿真的主干

能力 / 入口 载体 / 类型 说明
Power Analyzer by Keysight（AD 22.10+ 扩展）★电流仿真首选
Altium 官方扩展（Keysight 引擎）
电流/压降/电流密度AD 22.10 及以上版本的直流电源完整性（PI-DC）仿真扩展，也就是 AD 里做「电流仿真」的正解：不再是简单的横截面积估算，而是先精确建模铜箔结构，再解算整板供电电压与电流，输出【电压降 / 电流密度 / 过孔最大电流】三类结果。在 PCB 编辑器中以热力图（Heatmap）可视化，可直接定位电流密度热点与压降超标处，并用探针测量任意两点间差分电压或单点电流密度；支持多电源网络同步仿真，可生成带电压/电流裕度、功耗数据的 HTML 报告。以 .pdnaK 分析文档承载配置，结果查看/报告生成只需普通 AD 许可，跑新分析需要单独的 Power Analyzer 授权。
SI Analyzer by Keysight（高速信号完整性，Open Beta）★电磁/高速首选
Altium 官方扩展（Keysight 引擎）
高速/SI（阻抗-损耗）面向高速设计的布局后（post-layout）信号完整性检查扩展，覆盖高速设计最关键的四个参数：阻抗、延迟、插入损耗（IL）与回波损耗（RL）。启动后 PCB 数据以 ODB++ 格式导入求解器，可对网络类/差分对/xSignal 批量套用阻抗等约束规格，结果按网络给出计算值（达标绿色、超标红色），阻抗与延迟还能直接以热力图回标到 PCB 上，并提供单端/差分探针与完整分析报告。当前为 Open Beta，跑新分析需有效订阅。这是 AD 22+ 内做「高速电磁/传输特性评估」的官方入口。
Ansys Icepak（热仿真）＋ Altium ECAD 直接导入
商业（Icepak / Fluent CFD）
热仿真（焦耳热/结温）AD 本身没有原生热求解器，做「热仿真」的标准路径就是 Ansys Icepak：它可直接导入 Altium Designer 的 ECAD 数据（也支持 ODB++ / IPC2581），自动把铜箔与过孔信息转成 PCB 各向异性导热系数图，再做板级/系统级稳态与瞬态热流分析（传导+对流+辐射）。更关键的是多物理场链路：SIwave 的直流配电损耗可双向传给 Icepak 做焦耳热分析，Q3D 提取的直流功耗可作为热源，HFSS 与 Icepak 可做电磁-热耦合，温度结果还能送进结构力学算热应力。
Mixed-Signal Circuit Simulation（AD 内置 SPICE 仿真）
AD 原生
电路级电流/瞬态AD 内建的混合信号电路仿真器（原理图级，基于 XSPICE/SIMetrix 引擎）：可做直流工作点、瞬态（看器件电流/电压波形）、AC 扫描、噪声与傅里叶分析，用于电源环路、放大器、滤波等电路级的电流与波形仿真；配合 SIMetrix/SIMPLIS 高级引擎可做开关电源与环路稳定性分析。属于「电路级」，与上面的「板级 PI-DC/热/EM」互补。
Advanced Sim Model / IBIS-AMI 支持
AD 原生
高速信号完整性AD 支持挂载厂商 IBIS / IBIS-AMI 缓冲器模型与高级仿真模型，可在原理图/信号层做高速串行链路（PCIe / DDR / USB3）的反射、串扰与眼图趋势评估，是高速设计前期最省成本的仿真切入点，也是接 Ansys/HFSS 之前的快速筛选手段。
Layer Stack Manager + Impedance Calculator
AD 原生
阻抗/叠层基础叠层管理器与阻抗计算器：定义介质厚度/介电常数、铜厚与线宽间距，自动反算单端/差分阻抗。它既是高速板「阻抗控制」的源头配置，也是上面所有 SI/EM/热仿真能算准的几何与材料基础（叠层不对，仿真结果全部失真）。
PDN Analyzer by CST（上一代产品，已被取代）
Legacy
Legacy（历史参考）Altium 早期与 CST（现属达索 SIMULIA）合作的电源完整性扩展，功能上与 Power Analyzer 重叠。AD 22+ 用户请优先使用 Power Analyzer by Keysight；老工程/老文档里遇到 PDN Analyzer 时按此理解即可。

四、落地建议

  1. 【最重要的结论】GitHub 上不存在「直接嵌进 Altium Designer 内部、开箱做电流/热/电磁仿真」的成熟开源插件。AD 22+ 的仿真能力由三条官方/商业线构成，且三条线各管一块：① 电流 → Power Analyzer by Keysight（AD 22.10+ 扩展，PI-DC：电压降/电流密度/过孔电流）；② 高速信号/电磁 → SI Analyzer by Keysight（Open Beta：阻抗/延迟/插入损耗/回波损耗）；③ 热 → AD 无原生求解器，必须走 Ansys Icepak（可直接导入 AD 的 ECAD 数据，并与 SIwave/Q3D/HFSS 做焦耳热与电磁-热耦合）。
  2. 务实的落地组合是「AD 出数据 → 求经济性用开源引擎算」：用 wavenumber-eng/altium_monkey、vadmium/python-altium、Altium-Designer-addons 脚本把叠层、网表、Gerber、3D 模型导出来，再接 ngspice / PySpice / Xyce（电流与瞬态）、Elmer FEM / heatrapy（热传导与结温）、openEMS / antmicro gerber2ems（走线电磁与 S 参数）做批量参数扫描——这批引擎免费且可脚本化，适合做设计前期的探索与回归。
  3. 若希望「在 EDA 内部一键仿真」，目前成熟的开源样本全部长在 KiCad 生态（NBalciunas/kicad-rfsim 直接算 S 参数、antmicro/kicad-si-simulation-wrapper 准备 openEMS 仿真、aklofas/kicad-happy 做 AI 辅助评审）。把 AD 工程经 thesourcerer8/altium2kicad 转成 KiCad，是成本最低的开源仿真落地路径。
  4. AI + 仿真正在快速成型，值得先小范围试点：salitronic/eda-agent 与 coffeenmusic/altium-mcp 能让 Agent 直接驱动活的 AD 会话；ansys/pyaedt 用 Python 脚本化 HFSS/SIwave/Q3D/Icepak；MPh-py/MPh 脚本化 COMSOL；svd-ai-lab/sim-cli 把 COMSOL/ANSYS 的 CAE 文件转成结构化文本交给 Agent 读写。方向是「自然语言 → 参数化建模 → 批量求解 → 结果解读」。
  5. 采购视角的提醒：Power Analyzer 与 SI Analyzer 都需要在 AD 许可之外单独授权（SI Analyzer 目前 Open Beta），Ansys Icepak/SIwave/Q3D/HFSS 是另一套预算。若只是想先在板级看电流密度与压降，先申请 Power Analyzer 试用往往比买整套 Ansys 更划算。
